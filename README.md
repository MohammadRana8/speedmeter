# Speed Meter (Android)
Live network speed, daily mobile/Wi-Fi usage, monthly cycle, data cap with 80% / 100% alerts.

## Get the APK
1. Push this project to GitHub (keep the `.github/workflows/build.yml` file).
2. Open the **Actions** tab, pick **Build APK**, wait for the green check.
3. Open the run, download **speedmeter-debug-apk** under Artifacts, unzip, install the APK.
   (Allow "install unknown apps" for your browser/files app.)

Debug build only; a Play Store release needs signing. Rename `com.example.speedmeter` before publishing.
